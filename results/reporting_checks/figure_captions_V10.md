# Revised figure captions and provenance

**Fig. 1. Derivation of the predictive cohort.** Patient and index–follow-up pair counts from the source extract through HbA1c cleaning, outcome-window eligibility and allocation to the primary temporal, patient-disjoint training, validation and test partitions. The descriptive cohorts are defined in Supplementary Fig. S1. All counts are unchanged from V9; the layout has been rebuilt to prevent clipping.

**Fig. 4. HbA1c distributions and longitudinal glycaemic transitions.** (A) Baseline HbA1c in all 381,374 patients with at least one valid day-level draw. (B) Within-patient change, calculated as final minus baseline HbA1c, in the longitudinal cohort with at least two draws and a non-zero change (N = 190,697); negative values indicate improvement. (C) Row-normalised probabilities of transition from each baseline HbA1c stratum to each final stratum. (D) Proportion with final HbA1c below 7.0%, by baseline stratum, with 95% Wilson score intervals; intervals may be narrower than the plotting symbols. All draws were within the prespecified 2–20% range. Histograms display the 0.5th–99.5th percentile range without excluding observations from the reported statistics. Transition counts are given in Supplementary Table S26; the sensitivity analysis including 11,070 patients with unchanged baseline and final values is in Supplementary Table S22.

**Fig. 7. Robustness and the contribution of numeric representation.** (A) Macro AUROC under changes to the data split, outcome-change threshold and follow-up window. (B) Transformer optimisation variants, with the primary transformer and LightGBM results shown as reference lines; rate denotes the learning rate and MLM denotes masked-language modelling. (C) Information-matched factorial comparison: both model families receive the same 96-token history window, either as binned tokens alone or supplemented with index HbA1c, age, sex, visit count and sequence length. Each result averages predicted probabilities over three seeds; the transformer performs better on binned inputs, whereas LightGBM performs better after the numeric covariates are added. Paired patient-clustered differences and confidence intervals are given in Supplementary Table S20. (D) Learning curves from nested subsets of training patients, evaluated on the unchanged temporal test partition.

## Data provenance and validation

- Fig. 1 uses the existing V9 flow counts and changes only presentation.
- Fig. 4 histograms were regenerated from the two original HbA1c CSV extracts using the existing cleaning rules: readable timestamp, value within 2–20%, removal of exact patient/timestamp/value duplicates, and averaging by patient-day. Assertions confirmed 1,131,455 cleaned measurements, 1,128,790 patient-day draws, 381,374 patients with a valid draw and 190,697 patients in the non-zero-change longitudinal cohort. Every cell of the transition matrix matched Supplementary Table S26 exactly. No patient-level data were written.
- Fig. 7A, B and D read the existing aggregate sensitivity, optimisation and learning-curve CSV files. Fig. 7C uses the four existing Table S20 estimates on the shared 96-token window; it adds no new model fitting.
- All figures are supplied as 400-dpi PNGs and editable vector SVGs. Figure generation uses the bundled Python runtime and a task-local matplotlib installation. The reproducible builder is in `tmp/v10_editorial/build_v10_figures.py`.
